# Contributing

Bug reports, feature ideas, and pull requests are welcome.

## Local Setup

```bash
./script/build_and_run.sh
```

## Packaging

```bash
./script/package_dmg.sh
```

## Notes

- Keep the app native and menu-bar-first.
- Use Apple Calendar through EventKit.
- Keep the menu compact and system-looking.
- Do not commit local build artifacts from `.build/` or `dist/`.
